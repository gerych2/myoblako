## 📝 Примечания

### Для запуска Google Analytics:
1. Создайте файл `.env` в корне проекта
2. Добавьте: `VITE_GA_ID=G-XXXXXXXXXX`
3. Замените `G-XXXXXXXXXX` на ваш реальный ID

### Для изменения даты окончания акции:
Откройте `src/pages/Home.jsx` и измените:
```jsx
<SaleTimer 
  endDate="2026-05-15T23:59:59"
  title="Весенняя распродажа — скидки до 30%"
/>
```

### Цветовая схема:
Все цвета определены в `src/index.css` в `:root` переменных.
