# 🚀 Как запустить сайт

## Шаг 1: Откройте терминал в папке проекта
Откройте PowerShell или командную строку в папке `bedding-store`

## Шаг 2: Запустите сервер разработки
```bash
npm run dev
```

## Шаг 3: Откройте браузер
После запуска вы увидите сообщение:
```
  VITE v6.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```

Откройте в браузере: **http://localhost:5173/**

---

## 🎨 Что вы увидите:

### Главная страница
- Красивый заголовок с градиентом
- 6 карточек товаров с постельным бельем

### Карточки товаров (при наведении курсора)
- ✨ Изображение увеличивается
- 💰 Появляется цена крупным шрифтом
- 📝 Показывается описание товара
- 🎨 Можно выбрать цвет (кружочки)
- 📏 Можно выбрать размер (кнопки)

### Корзина
- Нажмите на кнопку корзины в правом верхнем углу
- Справа выедет красивая панель с товарами
- Можно изменить количество (+/-)
- Можно удалить товар (🗑️)
- Нажмите "Оформить заказ" для формы заказа

### Оформление заказа
- Заполните имя, телефон, адрес
- Доставка бесплатная!
- Нажмите "Подтвердить заказ"

---

## 🛠️ Если что-то не работает:

### Ошибка "npm не найден"
Установите Node.js с официального сайта: https://nodejs.org/

### Ошибка при установке
Попробуйте удалить папку `node_modules` и файл `package-lock.json`, затем:
```bash
npm install
```

### Порт 5173 занят
Vite автоматически выберет другой порт (5174, 5175 и т.д.)

## 🎨 Хотите изменить дизайн?

### Изменить цвета
Откройте файл `src/index.css` и измените:
```css
--primary: #6366f1;      /* Основной цвет */
--secondary: #ec4899;    /* Дополнительный цвет */
--accent: #f59e0b;       /* Акцентный цвет */
```

### Добавить товары
Откройте файл `src/App.jsx` и добавьте товары в массив `products`
