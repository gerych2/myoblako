# MYOBLAKO - Постельное белье премиум класса

Современный интернет-магазин постельного белья премиум класса с роскошным дизайном и продвинутым функционалом.

## 🚀 Возможности

### ✨ Основной функционал
- **Прелоадер** - Красивая анимация загрузки с брендированным логотипом
- **Анимации** - Плавные переходы и микроанимации по всему сайту
- **Адаптивный дизайн** - Полная поддержка мобильных устройств

### 🛍️ E-commerce функции
- **Корзина** - Полнофункциональная корзина с сохранением в localStorage
- **Избранное** - Сохранение понравившихся товаров
- **Сравнение** - Сравнение до 4 товаров одновременно
- **Фильтры** - Поиск и фильтрация по цене, размеру, материалу
- **Сортировка** - Сортировка товаров по различным параметрам

### 🎨 UX/UI улучшения
- **Уведомления** - Toast notifications для всех действий
- **Breadcrumbs** - Навигационные хлебные крошки
- **Мобильное меню** - Красивое выдвижное меню для мобильных
- **Прогресс оформления** - Визуальный прогресс при оформлении заказа
- **Таймер акций** - Countdown таймер для специальных предложений

### 📊 Аналитика и SEO
- **Google Analytics** - Полная интеграция с отслеживанием событий
- **SEO оптимизация** - Мета-теги, Open Graph, Twitter Cards
- **Отслеживание событий** - E-commerce события (добавление в корзину, покупки и т.д.)

## 🛠️ Технологии

- **React 18** - Современный UI фреймворк
- **React Router** - Маршрутизация
- **Vite** - Быстрая сборка
- **Context API** - Управление состоянием
- **LocalStorage** - Сохранение данных
- **Google Analytics** - Аналитика

## 📦 Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/myoblako.git

# Перейдите в директорию
cd bedding-store

# Установите зависимости
npm install

# Скопируйте .env.example в .env и настройте
cp .env.example .env

# Запустите dev сервер
npm run dev
```

## ⚙️ Настройка Google Analytics

1. Создайте аккаунт Google Analytics
2. Получите ваш Measurement ID (формат: G-XXXXXXXXXX)
3. Создайте файл `.env` в корне проекта
4. Добавьте ваш ID:
```
VITE_GA_ID=G-XXXXXXXXXX
```
