# 🛏️ DreamBed - Магазин постельного белья премиум класса

## 🎨 Что получилось

### 1. Главная страница
- **Шапка сайта** с логотипом 🛏️ DreamBed
- Навигационное меню (Каталог, О нас, Доставка, Контакты)
- Кнопка корзины с счетчиком товаров
- Красивый заголовок с градиентом: "Постельное белье **премиум класса**"
- Подзаголовок: "Роскошь и комфорт для вашего идеального сна"

### 2. Карточки товаров (6 штук)

1. **Роскошный сатин "Midnight Dreams"** - 8 990 ₽
   - Премиум сатин, 100% хлопок, плотность 120 г/м²
   - Цвета: синий, фиолетовый, бордовый
   
2. **Элегантный шелк "Pearl Luxury"** - 15 990 ₽
   - Натуральный шелк, гипоаллергенный, терморегуляция
   - Цвета: белый, кремовый, розовый
   
3. **Бамбуковое волокно "Eco Dream"** - 6 990 ₽
   - Экологичный бамбук, антибактериальный эффект
   - Цвета: зеленый, бирюзовый, синий
   
4. **Перкаль "Cloud Comfort"** - 7 490 ₽
   - Мягкий перкаль, дышащая ткань, долговечность
   - Цвета: светло-синий, лавандовый, розовый
   
5. **Жаккард "Royal Palace"** - 12 990 ₽
   - Роскошный жаккард с узором, премиум качество
   - Цвета: коричневый, бордовый, темно-синий
   
6. **Лен "Natural Breeze"** - 9 490 ₽
   - 100% лен, натуральный, идеален для лета
   - Цвета: белый, бежевый, серый

#### Эффекты карточек:
- ✨ **При наведении курсора:**
  - Карточка поднимается вверх и немного увеличивается
  - Изображение плавно увеличивается (zoom эффект)
  - Появляется темный градиент снизу
  - **Цена** появляется крупным белым шрифтом (2.5rem)
  - **Описание** появляется под ценой
  - Справа вверху появляется бейдж "✨ Наведите для деталей"
  - Эффект блеска проходит по карточке

- 🎨 **Выбор цвета:**
  - Цветные кружочки под названием
  - При клике - обводка с тенью
  - При наведении - увеличение

- 📏 **Выбор размера:**
  - Кнопки с размерами (1.5-спальный, 2-спальный, Евро, King Size)
  - Выбранный размер - градиентный фон
  - При наведении - поднимается вверх

- 🛒 **Кнопка "Добавить в корзину":**
  - Градиентный фон (синий → розовый)
  - Иконка корзины
  - При наведении - поднимается с тенью

### 3. Корзина (боковая панель)

#### Внешний вид:
- Выезжает справа с плавной анимацией
- Ширина: 500px
- Белый фон с тенью
- Заголовок: "🛒 Корзина" на градиентном фоне

#### Функционал:
- **Список товаров:**
  - Миниатюра изображения (80x80px)
  - Название товара
  - Выбранный цвет (кружочек)
  - Выбранный размер
  - Цена с градиентом
  - Кнопки +/- для изменения количества
  - Кнопка удаления 🗑️

- **Подвал корзины:**
  - Общая сумма крупным шрифтом с градиентом
  - Кнопка "Оформить заказ" с иконкой стрелки

- **Пустая корзина:**
  - Иконка 🛏️
  - Текст "Корзина пуста"
  - Подсказка "Добавьте товары для оформления заказа"

### 4. Форма оформления заказа

#### Поля формы:
- **Ваше имя** (обязательное)
- **Телефон** (обязательное)
- **Адрес доставки** (обязательное, textarea)
- **Комментарий к заказу** (необязательное, textarea)

#### Сводка заказа:
- Количество товаров
- Доставка: **Бесплатно** (зеленым цветом)
- Итоговая сумма

#### Кнопки:
- **← Назад** - вернуться к корзине
- **Подтвердить заказ** - отправить заказ (зеленая кнопка)

### 5. Анимации и эффекты

#### Карточки товаров:
- Плавное появление при загрузке
- Подъем и увеличение при наведении (transform + scale)
- Zoom изображения
- Появление overlay с информацией
- Эффект блеска (shimmer)
- Анимация бейджа

#### Корзина:
- Выезжание справа (slide-in)
- Появление overlay с blur
- Анимация добавления товара (slideIn)
- Bounce анимация счетчика товаров
- Плавное переключение между корзиной и формой

#### Кнопки:
- Подъем при наведении
- Изменение тени
- Плавные переходы цветов
- Вращение кнопки закрытия

### 6. Цветовая схема

```css
Основной цвет (primary): #6366f1 (индиго)
Дополнительный (secondary): #ec4899 (розовый)
Акцентный (accent): #f59e0b (оранжевый)
Текст: #1f2937 (темно-серый)
Текст светлый: #6b7280 (серый)
Фон: #ffffff (белый)
```

### 7. Градиенты

- **Кнопки:** синий → розовый (135deg)
- **Заголовок:** синий → розовый
- **Фон страницы:** светло-серый → голубоватый
- **Overlay карточек:** прозрачный → черный (сверху вниз)

### 8. Адаптивность

- **Десктоп:** 3 колонки карточек
- **Планшет:** 2 колонки
- **Мобильный:** 1 колонка
- Корзина на мобильных занимает весь экран

### 9. Технические детали

- **React 18** - современные хуки (useState)
- **Vite** - мгновенная горячая перезагрузка
- **CSS3** - transitions, transforms, animations
- **Unsplash** - качественные изображения
- **Без зависимостей** - чистый React + CSS

### 10. Уникальные фишки

✨ **Что делает этот сайт особенным:**

1. **Карточки не как у всех** - информация появляется прямо на изображении при наведении
2. **Эффект блеска** - световая волна проходит по карточке
3. **Плавные градиенты** - везде, где возможно
4. **Микроанимации** - каждое действие с обратной связью
5. **Современный UI** - скругленные углы, тени, backdrop-blur
6. **Интуитивный UX** - все понятно без инструкций
7. **Быстрая работа** - никаких тормозов
8. **Красивая типографика** - крупные заголовки, читаемый текст
